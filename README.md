# 📦 Product Management System

## 📌 Project Overview

The Product Management System is a Python-based console application developed to manage products, customers, administrators, and suppliers efficiently. It uses MySQL as the database and PyMySQL for database connectivity.

The application provides separate login and management functionalities for Admin, Customer, and Supplier users.

## 🚀 Features

### 🔐 1. Admin Management
- Admin Registration
- Admin Login
- View Admin Details
- Change Password
- Update Admin Profile
- Delete Admin Account

### 👤 2. Customer Management
- Customer Registration
- Customer Login
- View Customer Details
- Change Password
- Update Customer Profile
- View Available Products
- Search Products

### 🏢 3. Supplier Management
- Supplier Registration
- Supplier Login
- View Supplier Details
- Change Password
- Update Supplier Profile
- View Products
- Search Products

### 📦 4. Product Management
- Add New Products
- View Product Details
- Search Products
- Update Product Information
- Delete Products
- Manage Product Categories
- Track Product Quantity
- Maintain Minimum Stock Levels

### 📋 5. Supplier Details
- Add Supplier Information
- View Supplier Details
- Manage Supplier Contact Information

## 📥 Installation

Install PyMySQL:

```bash
pip install pymysql
```

## ▶️ How to Run

1. Clone the GitHub repository.
2. Open the project in VS Code.
3. Install the required Python libraries.
4. Create a MySQL database named `products`.
5. Create the required database tables.
6. Configure the MySQL username and password in `pdcode.py`.
7. Run the main Python file.

```bash
python main.py
```
